🔗 Merge and Sort Two Lists in Python
📌 Description

This program merges two lists and then sorts the combined list in ascending order.
It uses simple Python list operations, making it easy to understand for beginners.

🧩 Problem Statement

Given two lists:

list1 = [1, 3, 5]
list2 = [2, 4, 6]


Merge them and sort the result.

✅ Code
list1 = [1, 3, 5]
list2 = [2, 4, 6]

merged = list1 + list2
merged.sort()

print(merged)

🧠 Explanation

list1 + list2 combines both lists into one

sort() arranges the elements in ascending order

The final sorted list is printed

🛠 Concepts Used

Lists

List concatenation

sort() method

🖨 Example Output
[1, 2, 3, 4, 5, 6]
